## 缺陷和实现断言

- 中文模式下存在拼音组合时短按 Shift 或按 Ctrl+Space，切换前必须提交原始输入；
- 模式切换后组合、候选列表和候选位置必须同时失效，方向键和翻页键回到应用；
- 空闲状态切换模式不得产生 commit；
- 2.0.4 的回车英文提交与方向键透传、空格透传、编辑、标点、Emoji 和学习功能不得回退。
